# OpenList 用户管理

## 项目定位

独立运行的 OpenList 用户管理后台，用于创建和管理普通 WebDAV 用户。

## 运行状态

这是一个独立的 Python Web 服务,使用独立进程监听 `0.0.0.0:19100`。

## 功能

- 独立后台账号密码登录；
- 登录失败只显示错误提示，不展示后台内容；
- 修改后台密码后清除会话并强制重新登录；
- 用户名即时检查；
- 用户名只允许小写英文字母和数字；
- 禁止使用包含管理员相关词语或管理员账号的用户名；
- 创建普通 OpenList 用户：`role=0`、`permission=256`；
- 用户绑定 `base_path`；
- 周卡、年卡、自定义到期时间；
- 用户列表按用户名查询；
- 所有用户支持续费一年或两年；
- 停用、恢复、删除用户并同步 OpenList；
- 每 60 秒检查到期用户并自动停用；
- 新增用户后显示固定网易爆米花 WebDAV 配置文本；
- 配置文本支持复制和继续新增；
- 设置页面隐藏 OpenList 管理员密码，使用 `***` 展示；
- 页面支持移动端适配和 Cloudflare HTTPS 访问。
